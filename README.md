# Running Coach

Training log and plan for the **Phoenix 5K, Dec 26, 2026**, built with Claude Code as a running coach.

**Calendar:** https://daveedge1.github.io/RunningCoach/ · **Fitness:** https://daveedge1.github.io/RunningCoach/fitness.html

- `training-plan.md` explains the plan and `plan.csv` has it day by day
- `profile.md` holds HR thresholds, zones, races, and constraints
- `log.csv`, `data/runs.csv`, and `data/laps.csv` are run summaries from COROS. Raw FIT files and GPS data are not in the repo.
- `scripts/update.sh` syncs from intervals.icu, re-runs the analysis, rebuilds `docs/`, and pushes
